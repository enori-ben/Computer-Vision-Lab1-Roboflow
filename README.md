# Computer Vision Lab 1 — Roboflow

## Overview
This laboratory introduces four computer vision annotation tasks using Roboflow.

## Objectives
- Image Classification
- Object Detection
- Semantic Segmentation
- Keypoint Detection

## Exercises

### 1. Image Classification
- Project: `Lab1_Image_Classification`
- Required: At least 15 images
- Classes: Cat, Dog, Bird

### 2. Object Detection
- Project: `Lab1_Object_Detection`
- Required: At least 10 annotated images
- Classes: Person, Car, Bicycle
- Annotation type: Bounding boxes

### 3. Semantic Segmentation
- Project: `Lab1_Semantic_Segmentation`
- Required: At least 5 annotated images
- Classes: Road, Building, Vegetation

### 4. Keypoint Detection
- Project: `Lab1_Keypoint_Detection`
- Required: At least 5 annotated images
- Class: Person
- Keypoints: Head, Left shoulder, Right shoulder, Left elbow, Right elbow, Left wrist, Right wrist
